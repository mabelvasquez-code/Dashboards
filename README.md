# Comms Intelligence — MVP
Herramienta propia de gestión de comunicaciones.

## Ejecutar
Abre `index.html` en Chrome/Edge/Firefox.

## Compartir por link
Sube la carpeta a un hosting estático como GitHub Pages, Netlify, Vercel o Cloudflare Pages.

## Importante
Esta versión es un MVP: los datos se guardan en el navegador mediante localStorage. Para uso multiusuario se debe añadir una base de datos y autenticación.

## Evolución prevista
1. Base de datos central.
2. Usuarios/roles.
3. Google Analytics 4.
4. Google Search Console.
5. Meta/LinkedIn.
6. Histórico y comparación de períodos.
7. Alertas automáticas.
8. Exportación ejecutiva.
9. Motor de diagnóstico configurable por objetivo y KPI.
